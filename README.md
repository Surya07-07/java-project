# Student Course Registration System (SCRMS)

A simple and efficient **Java console application** that manages students, courses, and registrations.  
This project follows the **Build Your Own Project** guidelines and demonstrates modular Java programming, OOP concepts, architecture design, UML diagrams, and documentation.

---

## 📌 Project Overview

The Student Course Registration System allows administrators to:

- Add Students  
- Add Courses  
- Register Students to Courses  
- View all Students, Courses, and Registrations  

The system uses a clean menu-driven structure and ensures easy usage, maintainability, and modularity.

---

## 🚀 Features

### ✔ Student Management
- Add Student  
- View Students  

### ✔ Course Management
- Add Course  
- View Courses  

### ✔ Registration Management
- Register student to course  
- View all registrations  

### ✔ Other Features
- Validation for IDs  
- Error handling  
- Modular OOP structure
